设备用法

侧边触控条
上下滑动调音量，按住 Fn 滑动调屏幕亮度。长按 Fn + 空格 3 秒开启或关闭触控。
键盘背光
短按 Fn + ← 或 Fn + →，在常亮、呼吸和关闭之间切换。
无线连接
无线档下，Fn + 1 / 2 / 3 短按切换蓝牙设备，长按配对。按住 Fn + 4 约 1 秒连接 2.4 GHz 接收器，回连异常时可长按 3 秒重新配对。
恢复出厂设置
长按 Fn + 左 Shift + 退格 3 秒，红灯闪烁 3 次表示恢复成功。页面的「恢复快照」会先把保存的键位载入草稿。
