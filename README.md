# luofei-vivify

洛斐小顺 Flow 2 Mac 版 84 键的非官方配置工具。通过 USB 读取实机布局，在键盘图上改键，确认后写回。提供 macOS 桌面版和本地网页版。

## 支持范围

| 项目 | 支持情况 |
| --- | --- |
| 键盘 | Flow 2 84 for Mac（OE927），USB `388d:0028`，VIA 协议 12 |
| 系统 | macOS。桌面安装包构建目标为 Apple Silicon（arm64） |
| 连接 | 改键、宏和背光需使用 USB 数据线直连，并把键盘拨到有线档 |
| 配色预览 | 银色、深空灰、晴蓝、霞粉、曦黄。切换配色只改变界面外观 |
| 兼容性 | 其他型号、布局与协议版本未验证。深空灰参考 Flow 2 系列配色，设备适配仍按 USB ID 和协议筛选 |

配色名称参考洛斐产品页和中国大陆商品标注。 [Flow 2 84 for Mac](https://www.lofree.co/products/flow-2-84-low-profile-mechanical-keyboard-for-mac) · [Flow 2 84 深空灰](https://www.lofree.co/products/flow-2-84-low-profile-mechanical-keyboard) · [京东商品标注](https://www.jd.com/book/670634c075f754fe4fb.html)

## 从源码运行

需要 Node.js 22.18 或更新版本，以及 pnpm。使用锁文件安装：

```sh
pnpm install --frozen-lockfile
pnpm start
```

打开 <http://127.0.0.1:4312/>。服务只监听本机回环地址，端口可用 `VIVIFY_PORT` 修改。为了避免两个进程同时操作同一设备，改键时请只打开一种运行方式。

桌面开发与打包还需要 Xcode 命令行工具，用来构建 Swift 音量辅助程序。打包请在 Apple Silicon Mac 上用 arm64 Node.js 运行：

```sh
pnpm dev
pnpm package
```

`pnpm dev` 打开 Electron 窗口。`pnpm package` 在 `dist/` 生成 `mac-arm64/Flow 2 Keymap.app` 和带版本号的 DMG。构建脚本会做临时签名与校验，生成的安装包未经过 Apple 公证。首次启动时，如系统有提示，可在「系统设置 → 隐私与安全性」按系统提示检查。

## 使用方法

### 编辑与备份

1. 将键盘切到有线档并直连。应用从设备读取协议、层数和键位。连接多把同型号键盘时，请只保留要配置的一把。
2. 选一个层和一颗键，从分类或搜索里选择功能。支持 `cmd`、`bksp`、`音量` 和 `0x29` 等搜索方式。
3. 修改先进入草稿。可以撤销、重做或从「历史」回退。点「写入键盘」后逐键回读校验。
4. 重新连接后，若设备键值和草稿的基准不同，点「定位冲突」逐个处理。写入中断时，已确认的写入仍在设备上，未确认的改动可在重新读取后核对。

「保存快照」导出最近读回的键位，能读到宏时也会一并导出。请把快照当作个人配置保存，其中的宏可能含有用户录入的内容。「恢复快照」将键位差异载入草稿。宏会单独请求确认，确认后直接覆盖设备宏槽。写入宏或重置前，建议先保存快照。

网页版在同一个地址下会保存草稿、历史、配色、选中的键、层和分类。桌面版使用临时端口，同一次运行可以读回本地状态，退出后重开可能分配到不同地址。需要跨次保留的配置请导出快照。

### 宏、按键测试与重置

- 「宏」支持读取和编辑 16 个槽位并录制组合键。保存时整份写入并校验。宏存储写入中断后，可以重新导入一份包含完整宏槽的快照。
- 「按键测试」依据浏览器接收到的按键事件高亮界面，用于核对改键结果。系统保留的组合键可能不会传到页面。
- 「重置键盘」按仓库的实机出厂键位基准恢复可见键位。实体键盘的整机恢复出厂操作见「设备用法」。

### 快捷控制

点击键盘右侧或「快捷控制」：

- **Mac 音量**支持拖动实时调节，并可静音或取消静音，键盘断开时也能用。可发送系统音量键事件时会尝试显示 macOS 原生音量提示，应用内同时提供反馈。
- **键盘背光**支持关闭、四档亮度、常亮和呼吸。连接有线键盘后才能操作，调整会回读。当前设置没有做断电持久化验证。
- **实体触控条开关、无线配对和屏幕亮度**目前通过键盘操作。触控条长按 `Fn + 空格` 3 秒开关，详情见「设备用法」。部分厂商键值的具体用途仍待实测。

| 快捷键 | 作用 |
| --- | --- |
| ⌘Z | 撤销 |
| ⇧⌘Z / ⌘Y | 重做 |
| ⌘S | 写入待处理的键位 |
| ⌘F | 聚焦键位搜索 |
| Esc | 关闭对话框 |

## 排查与贡献

- **找不到键盘**：检查 USB 线支持数据传输、键盘已切到有线档，并关闭同时打开的其他 VIA 编辑器。macOS 提示时，检查当前终端或桌面应用的输入设备访问权限。
- **系统音量可调但无原生提示**：检查当前运行程序是否能发送系统媒体键事件。网页版会尝试使用已有的辅助程序，或在本机具备 Xcode 命令行工具时编译。应用内提示仍可用。
- **要提交问题**：请提供 macOS 版本、运行方式、键盘型号、连接方式、复现步骤和可见报错。分享快照前先检查是否包含私人宏。
- **开发验证**：`pnpm check` 运行类型检查，`pnpm smoke` 在 Electron 窗口里检查搜索、层状态和快照导出。实机开发探测脚本在 `scripts/`，出厂基准采集前先核对设备状态和原有备份。

## 数据、隐私与许可证

应用的编辑与设备通信在本机执行。键位草稿和预览设置保存在浏览器本地存储，快照由用户自行导出。Mac 音量控制通过系统脚本与可选的本机辅助程序完成。

本项目自行编写的代码和文档按 [MIT 许可证](LICENSE) 提供。依赖使用各自的许可证。洛斐、Flow 2 和 VIA 名称用于标识兼容对象。本项目与这些厂商或项目没有隶属关系。

`public/oe927-layout.json` 记录该机型的设备 ID、矩阵坐标和键宽等布局事实。`data/oe927-default-keymap.json` 来自出厂状态的实机读回。包内不分发厂商 PDF 或原版 VIA 配置 JSON。设备通信与布局实现参考了公开的 [VIA 规范](https://www.caniusevia.com/docs/specification/) 和 [QMK 文档](https://docs.qmk.fm/)。
