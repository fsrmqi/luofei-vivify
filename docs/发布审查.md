# 开源发布审查

审查范围包含界面、本机 HTTP 服务、VIA 读写、macOS 音量辅助程序、诊断工具、Electron 打包、依赖和仓库内的数据。所有验证都以 Flow 2 84 for Mac（OE927）和当前运行环境为准。

## 已处理

| 范围 | 修订 |
| --- | --- |
| 界面与说明 | 配色采用银色、深空灰、晴蓝、霞粉、曦黄。明确区分配色预览和设备支持范围。README 整合运行、打包、功能限制、故障排查和数据说明。 |
| 键盘数据 | 原厂 VIA JSON 曾以两份相同文件纳入仓库。当前应用改用仅记录设备 ID、矩阵、键位坐标和键宽的内部布局，保留原来的 84 个位置。出厂键位基准仍来自实机读回。 |
| 设备操作 | 宏要求完整槽位，校验键值、文本与容量，保留末字节作为写入标志，写后按字节核对。录制结束时补齐修饰键释放。重置失败时保留未确认的草稿。 |
| 本机服务 | 校验回环地址、会话和写入来源。请求体按字节限长，损坏的 JSON 明确报错，设备枚举异常不会直接终止服务。原生音量辅助程序只接收固定的音量动作。 |
| 构建与依赖 | DMG 文件名读取项目版本。打包脚本禁用自动发布。为打包依赖中的 `minimatch` 加入修复版本覆盖。 [依赖公告](https://github.com/advisories/GHSA-g3hv-75wg-m249) |
| 隐私 | 宏探测脚本保留数量、大小等诊断信息，省略可能含有用户录入内容的字节。检查了工作区和 Git 历史差异中的常见密钥格式，未发现匹配。 |

## 验证方式

- `pnpm check`、JavaScript 语法检查与 `git diff --check`。
- `pnpm smoke` 验证 84 个键、五种配色、搜索、同次运行的层记忆和快照导出。Chromium 和 WebKit 另行核对了深空灰切换与重载后保留。
- 本机接口验证包含正常读取、错误 JSON、请求大小限制和来源校验。实机只读确认 6 层、16 个宏槽和可读取的背光状态。宏写入和中断恢复逻辑用模拟设备验证。
- Apple Silicon 的 Electron 应用完成构建和临时签名校验。检查包内包含项目许可证、布局和音量辅助程序，实际启动后读取到实机 6 层。
- `pnpm audit --registry https://registry.npmjs.org` 修复后未报告已知漏洞。

## 公开前仍需确认

- **历史素材**。当前工作树和新构建不再包含厂商原始 VIA JSON 或 PDF。旧提交仍包含原始 JSON，尚未核实厂商对该文件的再分发授权。若要公开现有 Git 历史，先确认授权。也可以用审查后的工作树创建一个新的公开仓库。
- **安装包分发**。当前桌面包仅做临时签名。对外发布前，需要在干净的 macOS 环境验证安装、权限提示和原生音量辅助程序。正式签名和 Apple 公证仍待处理。
- **硬件边界**。仍需更多固件与连接模式测试。尤其是其他版本的 OE927、拔线后切回无线的行为、背光断电持久性，以及实机宏写入中断后的恢复。
- **桌面状态记忆**。桌面应用使用临时回环端口，目前通过快照跨启动保留配置。网页固定地址下的本地状态可跨启动读取。
